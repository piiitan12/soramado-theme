# 仕様書（Soramado・WordPress テーマ）

LP の WordPress テーマの仕様と、それを実現しているファイルの対応。コードの読み方は [`コード説明.md`](コード説明.md)、入れ方とセキュリティは [`../README.md`](../README.md)。

## 1. 概要

| 項目 | 内容 |
|---|---|
| 位置づけ | 前職で担当した社内新規事業の LP（未公開のまま終了）をもとに、社名・人物・実績・数字をすべて架空に置き換えて再構成した版 |
| 担当 | 要件整理・構成・コピー初稿・デザイン・実装（技術面は社内の助言あり） |
| 形 | 親テーマなしで動く単体の WordPress テーマ。LP 部分は静的版から `tools/build_theme.py` で生成 |
| 技術 | PHP（WordPress テーマ）・HTML・CSS（CSS 変数）・JavaScript（GSAP・ScrollTrigger・SplitType・Lenis。同梱）・Python（変換） |
| 必要なプラグイン | Advanced Custom Fields（ページの説明文）・Contact Form 7（お問い合わせ） |
| 画像 | 写真は Unsplash と Pexels、ロゴはこの作品のために作った架空のもの（`docs/写真とロゴの出典.md`） |

## 2. ページ構成

| ページ | URL（パーマリンク「投稿名」） | 中身 | ファイル |
|---|---|---|---|
| トップ（LP） | `/` | 区画：`#top`（ファーストビュー）・`#record`・`#community`・`#cases`・`#issues`・`#service`・`#profile`・`#contact`（お問い合わせフォーム） | `front-page.php`（生成物）・`header.php`・`footer.php` |
| プライバシーポリシー | `/privacy/` | 管理画面で書いた本文 | `page.php`・`page.css` |
| 送信完了 | 固定ページ（テンプレート「送信完了」） | お礼の文（本文が空なら既定の文） | `page-thankyou.php` |
| 404 | 存在しない URL | 案内文とトップへのボタン | `404.php` |
| その他 | 投稿・一覧など | 題名と本文だけ（このサイトでは使わない） | `index.php` |

全ページ共通のヘッダー（ロゴ・ナビ・SP はメニューボタン）とフッター → `header.php`・`footer.php`（生成物）

## 3. 機能

| 機能 | 仕様 | ファイル |
|---|---|---|
| ページ内リンク | ヘッダー・フッターのリンクで LP の各区画へ移動。LP 以外のページからは LP へ戻ってから移動 | `build_theme.py`（リンクの書き換え）・`main.js`（`initAnchors`） |
| スマホのメニュー | ボタンで開閉。行き先を選ぶ・Esc・画面を広げると閉じる | `main.js`（`initMenu`） |
| ヘッダーの色の切り替え | 濃い色の区画（`#issues`・`#contact`・フッター）の上に来たら、ロゴを白・ボタンを白丸に。少しでもスクロールしたらロゴを引っ込める | `main.js`（`initHeaderState`）・`design.css` |
| ファーストビュー | 写真 3 枚を少し引きながら重ねて入れ替え（1 枚 6 秒・入れ替え 1.8 秒）。読み込み時に上から順に表示、見出しは 1 文字ずつ。多角形がゆっくり漂う。スクロールで奥行き | `main.js`（`initHeroSlides`・`initHeroIntro`・`initHeroPoly`・`initHeroScroll`） |
| スクロールの演出 | 要素の出現（1 回だけ）、写真の視差、見出しを行ごとにせり上げる、濃い区画を幕のように立ち上げる、帯の写真をゆっくり引く、フッター上のロゴのせり上がり | `main.js`（`initReveal`・`initParallax`・`initHeadingReveal`・`initDarkCurtain`・`initBandPhotos`・`initLogo`） |
| 慣性スクロール | マウスなど細かく指せる操作のときだけ、スクロールに慣性を付ける | `main.js`（`initSmoothScroll`・Lenis） |
| 幅ごとの改行 | 見出しの改行を PC・タブレット・SP で出し分け（JS が動かないときは CSS で） | `main.js`（`pruneResponsiveBreaks`）・`design.css` |
| お問い合わせ | Contact Form 7。題名「ソラマド お問い合わせ」のフォームを呼ぶ（中身は `docs/お問い合わせフォーム.txt`）。見た目は試作と同じ | `front-page.php`（ショートコード）・`form.css` |
| 説明文 | 固定ページごとに ACF「ページの説明文」で入力。空ならキャッチフレーズ | `inc/acf-fields.php`・`inc/head-meta.php` |

## 4. 動きの約束

| 約束 | ファイル |
|---|---|
| 出現系（要素の出現・見出し・幕）は 1 回だけ。ロゴのせり上がりは画面に入り直すたびに再生し、視差・帯の写真・メインビジュアルの入れ替えは常に動く | `main.js` |
| GSAP などが読めなかったときも、中身は全部見える（隠すのは JS が動いたときだけ） | `main.js`・`design.css` |
| 動きを減らす設定（`prefers-reduced-motion`）では動きを止める | `main.js`・`design.css` |

## 5. 画面幅（ブレークポイント）

| 幅 | 呼び方 |
|---|---|
| 〜767px | SP |
| 768px〜1023px | タブレット |
| 1024px〜 | PC |
| 1440px〜 | 大きい画面向けの拡張 |

指定は `assets/css/design.css` の `@media`。ヒーローの背景だけ境目が 768px を含む（`max-width:768px`）。`main.js` の改行の出し分けも同じ境目を使う（ずれると片方だけ改行が消えるため）。

## 6. 表示・検索・安全の設定

| 項目 | 設定 | ファイル |
|---|---|---|
| タイトル | WordPress が出す（`title-tag`）。区切りは「｜」 | `inc/setup.php` |
| 説明文・OGP | description・og:title・og:description・og:type・og:url・og:image・og:site_name・twitter:card。画像はアイキャッチ、なければ `screenshot.png` | `inc/head-meta.php` |
| 検索に出さない設定 | テーマには書かない。「設定 → 表示設定」で切り替える | `header.php`（コメント） |
| WordPress の標準 CSS | ブロック用 CSS・絵文字・グローバルスタイルを外す | `inc/style-script.php` |
| WordPress の版の表示 | 出さない（`wp_generator` を外す） | `inc/style-script.php` |
| 管理バー | サイト側に出さない | `inc/style-script.php` |
| 直接アクセス | すべての PHP で、WordPress を通さずに開かれたら止める | 各 PHP の冒頭 |
| エスケープ | URL は `esc_url`、属性は `esc_attr` | `inc/head-meta.php` ほか |
| 開発用ファイル | `tools/`・`docs/` に `.htaccess`。サーバーには上げない | `tools/.htaccess`・`docs/.htaccess`・README |

## 7. 入れ方（概要）

1. このフォルダを `wp-content/themes/soramado/` に置き、テーマを有効にする
2. Advanced Custom Fields と Contact Form 7 を有効にし、題名「ソラマド お問い合わせ」のフォームを作る
3. 固定ページ（トップ・プライバシーポリシー〈スラッグ `privacy`〉・送信完了）を作り、トップを「ホームページ」に指定
4. パーマリンクを「投稿名」にする

詳しくは README。LP を直すときは静的版を直して `python3 tools/build_theme.py <静的版のフォルダ>`。
