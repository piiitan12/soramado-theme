# コード説明（Soramado・WordPress テーマ）

前職で担当した社内新規事業の LP（未公開のまま終了）をもとに、社名・人物・実績・数字をすべて架空に置き換えて再構成した版を、親テーマなしで動く単体の WordPress テーマにしたもの。担当は要件整理・構成・コピー初稿・デザイン・実装（技術面は社内の助言あり）。ページと機能の一覧は [`仕様書.md`](仕様書.md)、入れ方とセキュリティは [`../README.md`](../README.md)。

---

## 1. 全体の作り：「生成するファイル」と「手で書くファイル」

| 種類 | ファイル | 直すときは |
|---|---|---|
| **生成物** | `header.php`・`front-page.php`・`footer.php`・`inc/style-script.php`・`assets/` | 静的版の `index.html` を直して `tools/build_theme.py` を回し直す。直接は直さない（先頭に注意書き） |
| **手書き** | `style.css`（テーマ宣言）・`functions.php`・`inc/setup.php`・`inc/head-meta.php`・`inc/acf-fields.php`・`page.php`・`page-thankyou.php`・`404.php`・`index.php`・`page.css`・`form.css` | そのまま直す |

**静的版の場所**：静的版（正）はリポジトリの外（応募フォルダの `soramado-static/`）にある。リポジトリだけでは再生成できない。

**なぜ分けたか**：LP は静的な HTML で作り込み、WordPress へはスクリプトで変換する。手で写すと必ずどこかがずれ、「静的版を直したのに WordPress 側が古い」が起きる。静的版が変わったら回し直せば、テーマも必ず追いつく。

## 2. テンプレート階層（どの URL でどのファイルが使われるか）

| 開いたページ | 使われるファイル | 中身 |
|---|---|---|
| トップ（「設定 → 表示設定」でホームページに指定した固定ページ） | `front-page.php` | LP 本体（生成物） |
| 固定ページ（プライバシーポリシーなど） | `page.php` | 題名と、管理画面で書いた本文（`the_content()`） |
| テンプレート「送信完了」を選んだ固定ページ | `page-thankyou.php` | お礼の文。本文が空なら既定の文を出す（ファイル冒頭の `Template Name: 送信完了`） |
| 存在しない URL | `404.php` | 案内文とトップへのボタン |
| それ以外（投稿・一覧など） | `index.php` | WordPress が必ず求める受け皿。このサイトは投稿を使わないので、題名と本文を並べるだけ |

どのページも `get_header()`／`get_footer()` で、LP と同じヘッダー・フッターを使う。

## 3. 要所ごとの説明

### 3-1. `functions.php`（入口）
- **何をしているか**：`inc/` の 4 ファイルを読み込むだけ
- **なぜ**：役割ごとにファイルを分けると、どこを直せばいいかがファイル名で分かる。`style-script.php` は生成物なので、手書きのものと混ぜないためにも分けた

### 3-2. `inc/setup.php`（テーマの初期設定）
- `add_theme_support( 'title-tag' )`：`<title>` を WordPress に出させる（`header.php` に書かない）
- `post-thumbnails`（アイキャッチ）・`html5`（検索フォーム・ギャラリー・キャプション・style・script を HTML5 の書き方で出す）を有効にする
- タイトルの区切りを「｜」にする（`document_title_separator` フィルター）

### 3-3. `inc/style-script.php`（CSS・JS の読み込み・生成物）
- `wp_enqueue_style`／`wp_enqueue_script` で、`assets/css/design.css` と JS 5 本（GSAP・ScrollTrigger・SplitType・Lenis・main.js）を読む。`main.js` はライブラリ 4 本に依存する形で登録し、読み込み順を WordPress に任せる
- 版の番号（`SORAMADO_VER`＝静的版の書き出し日時）を付け、更新したときに古いファイルがブラウザに残らないようにする
- **ライブラリを同梱する理由**：CDN に頼らず、オフラインでも同じ見え方にするため。jQuery は使わない
- 手書きの `form.css`（お問い合わせフォーム）と `page.css`（LP 以外のページ）もここで読む。`page.css` はトップ以外だけ
- **WordPress が自前で足す CSS を外す**：ブロックエディタ用の CSS・絵文字・theme.json から作られる変数など。このテーマはブロックを使わないので、入れたままだと `design.css` と当たって見た目が静かにずれる。`global-styles` は `wp_dequeue_style` では消えないので、出している処理（`remove_action`）ごと外している
- `<head>` に WordPress の版を出さない（`wp_generator` を外す）。サイト側に管理バーを出さない（固定ヘッダーの下に潜り、ファーストビューの高さもずれるため）
- Contact Form 7 がフォームに自動で足す `<p>`・`<br>` を止める（隙間が二重になるため）

### 3-4. `inc/head-meta.php`（説明文と OGP）
- **何をしているか**：`wp_head` で `<meta name="description">`・`og:title`・`og:description`・`og:type`・`og:url`・`og:image`・`og:site_name`・`twitter:card` を出す
- 説明文は、固定ページの ACF 項目「ページの説明文」→ 空なら「設定 → 一般」のキャッチフレーズ → どちらも空なら出さない、の順
- OGP の画像は、アイキャッチがあればそれ、なければテーマの `screenshot.png`
- 値はすべてエスケープ（属性は `esc_attr`、URL は `esc_url`）

### 3-5. `inc/acf-fields.php`（ACF の項目をコードで持つ）
- **何をしているか**：`acf_add_local_field_group` で、固定ページに「ページの説明文（description）」の入力欄（テキストエリア・最大 200 文字）を出す
- **なぜ管理画面で作らないか**：管理画面で作ると定義がデータベースにしか残らず、別のサイトに入れるたびに作り直しになる。抜けると「説明文が空のまま公開」が静かに起きる。コードに書けば、テーマを有効にした時点で必ず出る
- 項目名 `page-description` は `head-meta.php` がこの名前で読む

### 3-6. `tools/build_theme.py`（静的版 → テーマへの変換）
- **何をしているか**：静的版の `index.html` を読み、次のことをして生成物を書き出す
  1. `<header>`・本体・`<footer>` に切り分け、`header.php`・`front-page.php`・`footer.php` にする（`get_header()`／`get_footer()` の形）
  2. 全体を包んでいる外側の箱（白い背景・横のはみ出し止め）を落とさずに残す。最初これを落として作り、背景を持たない区画に濃い色が透けたため
  3. `assets/…` の画像などのパスを、`get_stylesheet_directory_uri()` を使った URL に書き換える（`src`・`href`・`url()` の 3 通り）
  4. ヘッダーとフッターのページ内リンク（`#contact` など）を、LP 以外のページからも LP へ戻れる形にする。サイト内の `/privacy/` なども `home_url()` で組む
  5. 見た目だけのフォーム（`<form>` が無い試作）を、Contact Form 7 のショートコードに差し替える。**id ではなく題名で呼ぶ**（本番サーバーでは id の番号が変わるため）
  6. Google フォントの読み込み行だけを拾って `header.php` に入れる
  7. `inc/style-script.php` を書き出し、`assets/` はまるごと入れ替える（消えた画像を残さないため）
- 生成した各ファイルの先頭に「直接編集しないこと」と、直接開かれたら止める 1 行を入れる

### 3-7. `assets/js/main.js`（動き）
- **方針**（ファイル冒頭に書いてある）：動きは「見せる」ためではなく「読みやすくする」ために使う。出現系（要素の出現・見出し・幕）は 1 回だけ。ロゴのせり上がりは画面に入り直すたびに再生し、視差・帯の写真・メインビジュアルの入れ替えは常に動く。GSAP が読めなかったときは、動きが無いだけで中身は全部見える。動きを減らす設定の人には全部止める
- デザインの原稿は `data-` 属性で動きを指定していた。本番の WordPress に外部のランタイムを持ち込まないよう、同じ属性を読む最小限の JS に置き換えた
- 主な処理（関数名）
  - `initReveal`：スクロールで現れる（IntersectionObserver）
  - `initParallax`：写真の軽い視差
  - `initLogo`：フッターの上のロゴがせり上がる（ページの終わりの合図）
  - `initAnchors`：ページ内リンク
  - `initMenu`：スマホのメニュー。行き先を選んだら閉じる・Esc で閉じる・画面を広げたら閉じる
  - `initHeaderState`：ヘッダーが濃い色の区画（`data-dark`）の上に来たら、ロゴを白・ボタンを白丸に入れ替える。少しでもスクロールしたらロゴを引っ込める
  - `initHeroSlides`：ファーストビューの写真 3 枚を、少し引きながら重ねて入れ替える（GSAP）
  - `initHeroPoly`・`initHeroIntro`・`initHeroScroll`：多角形をゆっくり漂わせる／読み込みのとき上から順に出す（見出しは SplitType で 1 文字ずつ）／スクロールで奥行きを作る（ScrollTrigger）
  - `initSmoothScroll`：スクロールに慣性を付ける（Lenis）。動きを減らす設定の人と、マウスのように細かく指せる操作でない端末（スマホ・タブレット）には入れない（`pointer: fine` で判定）
  - `initHeadingReveal`・`initDarkCurtain`・`initBandPhotos`：見出しを行ごとにせり上げる／濃い区画を幕のように立ち上げる／つなぎの帯の写真をゆっくり引く
  - `pruneResponsiveBreaks`：幅ごとの改行（`br.br-pc`・`br.br-tb`・`br.br-sp`）のうち、いまの幅で効かないものを先に取り除く。残っていると SplitType が見出しの途中に空白を入れるため
- 取り下げた演出（数字を回す・マウス追従）も、理由とともにコメントで残している

### 3-8. `assets/css/design.css`（見た目）
- 色や文字などを CSS 変数でまとめて管理する
- 画面幅の境目は 〜767／768〜1023／1024〜 の 3 段＋1440px 以上の拡張。ヒーローの背景だけ 768px を含む（`max-width:768px`）
- `@keyframes` は `@media` の中に置かない（中に書くと、その幅のときしか登録されないため）

### 3-9. `form.css`・`page.css`（手書きの見た目）
- `form.css`：Contact Form 7 のタグには style を直接書けないので、試作の各入力欄に入れていた値を CSS として当て、見た目を試作と同じにする
- `page.css`：プライバシーポリシー・送信完了・404 の見た目

### 3-10. セキュリティ
- すべての PHP の冒頭で、WordPress を通さずに直接開かれたら止める（`defined( 'ABSPATH' ) || exit;`）
- 画面に出す値はエスケープする
- 外部リンクの `target="_blank"` には `rel="noopener noreferrer"`
- `tools/` と `docs/` には外から読めないようにする `.htaccess`。サーバーには上げない（README）

## 4. 面接で聞かれたときの短い答え

| 聞かれそうなこと | 答えの芯 |
|---|---|
| なぜ静的版から変換しているのか | 手で写すと必ずずれる。静的版を正にして、スクリプトで毎回同じようにテーマにする |
| 親テーマなしにした理由 | 元は子テーマ。親テーマがないと動かず、製品名も残るので、単体で動くテーマに直した |
| ACF をコードで持つ理由 | 管理画面で作るとデータベースにしか残らず、別のサイトで作り直しになるため |
| WordPress の標準 CSS を外した理由 | ブロックを使わないテーマなので不要。残すとデザインの CSS と当たって見た目がずれる |
| 動きの方針 | 読みやすくするためだけに使う。出現系（要素の出現・見出し・幕）は 1 回だけ。ロゴのせり上がりは画面に入り直すたびに再生し、視差・帯の写真・メインビジュアルの入れ替えは常に動く。動きを減らす設定では止める |
